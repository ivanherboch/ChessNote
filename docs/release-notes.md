## ChessDuck 1.7.0

APK Android signé, 100 % hors-ligne (Android 8.0 et plus ; arm64-v8a, armeabi-v7a, x86_64).

### Nouveautés
- **100 000 problèmes Lichess** (au lieu de 50 000), les plus populaires en priorité. Lors d'une mise à jour, les nouveaux problèmes sont importés au premier lancement ; la progression est conservée.
- **Problèmes** : le thème choisi dans le catalogue reste affiché au-dessus de la grille, même quand le problème a un autre type principal ; le conseil porte sur le thème choisi.

### Installation
Téléchargez `ChessDuck-1.7.0.apk` ci-dessous, ouvrez-le sur l'appareil et autorisez l'installation depuis cette source.
